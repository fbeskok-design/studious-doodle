# Ламинирование ресниц: с нуля до профи

Полный образовательный курс для мастеров лэш-индустрии — от анатомии ресниц
до продвижения услуги и продаж. Материалы курса лежат в папке [`course/`](course/).

## Структура репозитория

```
course/
├── curriculum.md          — полная программа курса (11 модулей, тайминг, ДЗ)
├── landing.html            — продающий лендинг курса (готов к публикации)
└── bonuses/
    ├── consultation-script.md   — скрипт консультации и работы с возражениями
    ├── client-checklist.md      — чек-листы для мастера (до/во время/после процедуры)
    ├── pricing-calculator.md    — калькулятор себестоимости и цены услуги
    ├── content-plan.md          — контент-план для соцсетей на 4 недели
    └── certificate-template.md  — текст сертификата об окончании курса
bot/
├── system-prompt.txt       — системная инструкция ИИ-помощника @fotik_lash_school_bot
└── README.md               — как вставить инструкцию в бота и подключить счётчик вопросов
```

## Для кого курс

- Начинающие лэш-мастера, которые хотят добавить ламинирование в портфолио услуг
- Действующие мастера ресниц/бровей, расширяющие линейку услуг
- Владельцы студий, которым нужна программа обучения для найма и адаптации мастеров

## Как использовать

1. Пройдите `course/curriculum.md` — это основа для видео-уроков или очных занятий.
2. Используйте материалы из `bonuses/` как раздаточные материалы для учеников.
3. `landing.html` можно открыть в браузере или разместить на любом хостинге — это
   готовая продающая страница для набора учеников на курс.
