# Чек-листы мастера

## Чек-лист рабочего кейса

- [ ] Силиконовые валики размеров S, M, L, XL (по 2–3 пары каждого)
- [ ] Клей для валиков (безопасный для кожи века)
- [ ] Составы №1 (фиксация), №2 (питание/нейтрализация), №3 (кератин)
- [ ] Краска для ресниц + оксидант (если работаете с окрашиванием)
- [ ] Микробраши, ватные диски без ворса, ватные палочки
- [ ] Патчи под глаза (гидрогелевые)
- [ ] Обезжириватель / мицеллярная вода без масла
- [ ] Масло или сыворотка для ресниц (финишный уход)
- [ ] Одноразовые шпатели, перчатки
- [ ] Дезинфектор для рук и поверхностей
- [ ] Таймер
- [ ] Бланки согласия и анкеты клиента

## Чек-лист «до процедуры»

- [ ] Уточнены противопоказания и аллергии
- [ ] Клиент снял линзы и макияж глаз
- [ ] Подписано информированное согласие
- [ ] Подобран размер валика под изгиб и длину ресниц
- [ ] Патчи зафиксированы на нижнем веке

## Чек-лист «во время процедуры»

- [ ] Валик приклеен ровно, без заломов на веке
- [ ] Ресницы разложены равномерно, без пропусков и склеек
- [ ] Время выдержки состава №1 контролируется таймером
- [ ] Состав не попадает на кожу и слизистую
- [ ] Промежуточное снятие состава — влажным (не сухим) диском

## Чек-лист «после процедуры»

- [ ] Ресницы расчёсаны, направление роста ровное
- [ ] Нанесён финишный уход (масло/сыворотка)
- [ ] Клиенту выданы рекомендации на 48 часов
- [ ] Сделаны фото «до/после» (с согласия клиента)
- [ ] Запись на коррекцию через 6–8 недель предложена клиенту

## Памятка для клиента (можно распечатать и выдавать)

**Первые 48 часов после ламинирования ресниц нельзя:**
- мочить ресницы и умываться горячей водой
- пользоваться баней/сауной, посещать бассейн
- тереть глаза, спать лицом в подушку
- наносить жирные кремы и масла в зону роста ресниц

**Можно и нужно:**
- через 48 часов пользоваться маслом/сывороткой для ресниц 2–3 раза в неделю
- расчёсывать ресницы щёточкой утром
- записаться на повторную процедуру через 6–8 недель
