# Калькулятор себестоимости и цены услуги

## Формула расчёта себестоимости одной процедуры

```
Себестоимость = Расходники на 1 клиента + (Аренда в час × время процедуры)
                + (Амортизация инструментов ÷ число процедур на комплект)
```

## Пример расчёта расходников на 1 процедуру

| Позиция | Расход на процедуру | Примерная цена | Стоимость |
|---|---|---|---|
| Состав №1, №2, №3 (из тубы на ~15–20 процедур) | 1/17 тубы | 1500 ₽/туба | ~90 ₽ |
| Клей для валиков | небольшое кол-во | 800 ₽/флакон (100 процедур) | ~8 ₽ |
| Валики (переиспользуемые, амортизация) | — | 600 ₽ / 50 процедур | ~12 ₽ |
| Патчи, диски, микробраши | 1 набор | — | ~40 ₽ |
| Краска + оксидант (если с окрашиванием) | — | — | ~70 ₽ |
| Масло/сыворотка (финиш) | — | — | ~15 ₽ |
| **Итого расходники** | | | **~165–235 ₽** |

## Формула цены

```
Цена клиенту = Себестоимость + Оплата времени мастера (час × ставка)
              + Аренда/накладные + Целевая прибыль
```

**Пример:**
- Себестоимость расходников: 200 ₽
- Время мастера: 1 час × 800 ₽/час = 800 ₽
- Аренда/накладные (25% от ставки): 200 ₽
- Целевая прибыль (30%): ~360 ₽

**Итоговая цена: ~1 500–1 800 ₽** (сверьте с рынком вашего города — цена не должна
быть ниже себестоимости + минимальной оплаты времени).

## Как поднимать средний чек

- Пакет «Ламинирование + окрашивание» — дороже суммы услуг по отдельности на 10–15%,
  но выгоднее для клиента по времени
- Абонемент на 2 коррекции с фиксацией цены — увеличивает повторные визиты
- Продажа домашнего ухода (масло/сыворотка) как допродажа после процедуры
- Сертификат в подарок — приводит новых клиентов через существующих
