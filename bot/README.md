# Системная инструкция для ИИ-помощника @fotik_lash_school_bot

Файл [`system-prompt.txt`](system-prompt.txt) — готовая системная инструкция.
С ней помощник не только отвечает на вопросы, но и мягко ведёт человека к покупке премиума.

## 1. Заполните перед вставкой

| Что заменить | На что |
|---|---|
| `[цена]` | цена премиума числом, например `990` |
| `[контакт Фатимы, например @username]` | ваш Telegram-ник или ссылка для связи |

## 2. Куда вставить

Вставьте весь текст из `system-prompt.txt` туда, где в боте сейчас лежит системная
инструкция. В конструкторах это поле обычно называется «Системный промпт»,
«Роль», «Инструкция для ИИ» или «System prompt». В коде это сообщение с ролью
`system` (или параметр `system`), которое отправляется в нейросеть вместе с
вопросом пользователя.

Прежде чем вставлять новый текст, сохраните старую инструкцию где-нибудь отдельно.
Если что-то пойдёт не так, просто верните её обратно.

## 3. Счётчик бесплатных вопросов

Нейросеть сама не знает, сколько бесплатных вопросов осталось у человека. Поэтому
в инструкции есть две переменные, которые бот должен подставлять перед каждым
запросом:

- `{status}` — `бесплатный` или `премиум`;
- `{free_left}` — сколько бесплатных вопросов останется **после** текущего ответа.
  Было 3, человек задал вопрос, значит, подставляем `2`.

Если ваш конструктор не умеет подставлять переменные, удалите из инструкции весь
блок «ДАННЫЕ О ПОЛЬЗОВАТЕЛЕ» (три строки). Тогда помощник не будет напоминать
о лимите сам, а предлагать премиум будет только тогда, когда человек сомневается
или спрашивает о нём. Всё остальное продолжит работать как раньше.

Пример подстановки, если бот написан на Python:

```python
from pathlib import Path

PROMPT = Path("system-prompt.txt").read_text(encoding="utf-8")

def build_system_prompt(is_premium: bool, free_left: int) -> str:
    return (PROMPT
            .replace("{status}", "премиум" if is_premium else "бесплатный")
            .replace("{free_left}", "без ограничений" if is_premium else str(free_left)))
```

## 4. Кнопка оплаты

Нейросеть пишет только текст и сама показать кнопку не может. Кнопку добавляет бот:
прикрепите вашу существующую кнопку оплаты к ответу, когда у человека не премиум
и `free_left` равно `0`. По желанию её можно показывать уже при `1–2`. Инструкция
просит помощника написать «нажмите кнопку оплаты под сообщением», поэтому кнопка
должна быть именно под этим ответом.

## 5. Проверка

С тестового аккаунта проверьте четыре случая:

1. Обычный вопрос при 3+ бесплатных вопросах. Ожидается полезный ответ без рекламы.
2. Вопрос при 1–2 оставшихся. Ожидается ответ и короткое напоминание про премиум.
3. Последний бесплатный вопрос. Ожидается ответ, предложение премиума и кнопка оплаты.
4. Сообщение «а зачем мне премиум, я парикмахер». Ожидаются примеры задач для парикмахера.
